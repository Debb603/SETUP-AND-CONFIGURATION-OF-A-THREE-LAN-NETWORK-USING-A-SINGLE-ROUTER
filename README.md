# Structured Three-LAN Network Setup

## Project Overview
This project demonstrates the configuration of a structured three-LAN network using Cisco Packet Tracer. The network environment was designed to simulate real-world communication between multiple Local Area Networks (LANs) through a single router.

The setup includes routers, switches, PCs, laptops, and Ethernet cables configured to establish seamless communication between devices across different network segments.

---

## Network Components
- 1 Router
- 3 Switches
- PCs and Laptops
- Ethernet (Copper Straight-Through) Cables
- Cisco Packet Tracer

---

## Project Objectives
- Build a structured multi-LAN topology
- Configure inter-LAN communication using a single router
- Implement proper IP addressing
- Connect end devices through switches
- Test communication between networks

---

## Features
- Three separate LAN segments
- Router-based inter-LAN routing
- Structured IP addressing
- End-to-end device connectivity
- Connectivity verification using ping tests

## Network Design
The network consists of three LANs connected through a central router to enable communication between all connected devices.

-LAN 1                                        192.168.1.10                                      DHCP Server, 1 PCs. 2 laptop, 1 Switch
-LAN 2                                        10.0.0.25                                         DHCP Server, 2 laptop, 1 Switch
-LAN 3                                        172.32.5.50                                       DHCP Server, 1 PCs. 2 laptop, 1 Switch
