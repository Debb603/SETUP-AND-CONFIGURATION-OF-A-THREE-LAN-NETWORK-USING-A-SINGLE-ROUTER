# SETUP-AND-CONFIGURATION-OF-A-THREE-LAN-NETWORK-USING-A-SINGLE-ROUTER
A practical networking project focused on configuring a structured three-LAN environment using Cisco Packet Tracer. The setup integrates routers, switches, PCs, laptops, and Ethernet cables to establish inter-LAN communication, implement IP addressing, and simulate real-world network connectivity and routing operations.
